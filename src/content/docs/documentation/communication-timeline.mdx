Every client's page has a **Communication** card, view-only, showing that client's recent texts and calls pulled live from Quo, refetched automatically every 60 seconds. A **Quo** link in the card header opens the platform itself for anything this view doesn't cover. A smaller version of the same idea shows up as a message-bubble icon on each appointment row on Day Ahead, so staff can check recent contact without leaving that page.

## Telling automated messages from real ones

Outgoing texts the app itself sent automatically such as appointment reminders, questionnaire reminders, and referral outreach messages, are tagged with a small bot icon. Hovering it shows why it went out (which client, which reminder). This is worked out by cross-referencing the message against the app's own reminder/questionnaire/referral send logs, plus a fallback pattern match against the configured reminder templates for anything not caught in those logs, so nearly every automated send gets correctly labeled even if its originating log entry is missing.

On the Day Ahead popover specifically, this distinction also drives a visual cue: the message icon turns amber if the client has sent (or received) a real, non-automated message the same day as the appointment or the day before, a quick "have they been in touch recently" signal.

## Edge cases

- **This view only ever shows history for the client's phone number on file.** A message from a different number (a parent calling from a second phone, for instance) won't show up here even if it's about the same client.
- **We have no way of distinguishing between texts from the same number for different clients.** Johnny and Jimmy have the same mom, with the same phone, so her texts will always show up on both children's pages, no matter who the text is about.
