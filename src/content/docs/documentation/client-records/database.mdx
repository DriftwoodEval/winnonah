title: Database
---

The **Database** link in the nav (under Clients) shows records from across all clients in one table. Use the tabs at the top right to choose which table to look at: **Questionnaires** or **External Records**. You need the Database page permission to see it.

Filters and sorting are not saved, so each table starts fresh when you open it. To change a record, open the client's page. This page is for viewing only.

## Questionnaires

Use this table to answer questions like "which Conners 4 questionnaires are still pending?" or "who has been reminded three or more times?" without opening each client.

Each row is one questionnaire. It shows the client, the questionnaire, its status, the date it was sent, how many reminders have gone out, and the date of the last reminder. The status and reminder colors match the questionnaire table on each client's page. Click a client's name to open their page.

### By client

Switch from **List** to **By client** next to the search box to get one row per client. Each row shows how many of the client's questionnaires are done (completed or external), a count of each status, the oldest sent date, and the most reminders any of their questionnaires has had. Clients with the most questionnaires still outstanding are listed first. Click the arrow beside a client's name to see each of their questionnaires.

Progress only counts the questionnaires that match your filters. If you filter to a single questionnaire, "1 of 1 done" refers to that questionnaire only.

### Counts

The questionnaire names above the table show how many of each there are. Click one to filter the table to it, and click it again to remove the filter. The line above the table shows how many questionnaires match your filters and how many clients they belong to. Status counts are in the **Status** filter.

### Filtering and sorting

- Search by client name or questionnaire name with the search box.
- Click the filter icon on the **Client**, **Questionnaire**, **Status**, or **Reminders** column to pick one or more values. Each option shows how many rows it would match given your other filters.
- Click a column heading to sort by it. Click it again to reverse the order.
- **Clear filters** resets everything.

Archived questionnaires are hidden until you choose **Archived** in the Status filter.

## External Records

This table has one row per client who needs school records, has had a records request, or has records notes. It shows where each client's request stands:

- **Not requested**: records are needed but no request has been queued or sent.
- **Queued**: a request is set up and waiting to be sent.
- **On hold**: a request is waiting and has a hold date that has not passed.
- **Requested**: the request has been sent once.
- **Requested again**: the request has been sent more than once.
- **Reviewed**: records notes have been entered for the client.
- **Not needed**: the client's records status is Not Needed. These are hidden until you choose **Not needed** in the Status filter.

The other columns show the date of the most recent request, how many requests have been sent, the hold date if there is one, and when the records notes were last updated. Only requests from the client's current session count, so an old request from before a re-referral does not make a client look requested.

Search, the Client and Status filters, and sorting work the same as in the Questionnaires table. By default the table lists clients that still need action first.
